# Orbit

Local macOS menu bar companion. Preserve the approved Moss/Pearl/Midnight appearance.
Use Swift/AppKit/WebKit and system frameworks, no third-party runtime dependencies.
Read provider stores only. Do not print private task titles or file paths in diagnostics.
Google credentials belong in Keychain, never in source or web content.
Run `bash scripts/build.sh` and `build/Orbit.app/Contents/MacOS/Orbit --self-test` after substantive changes.
Use inline execution; do not delegate agents for this project.
