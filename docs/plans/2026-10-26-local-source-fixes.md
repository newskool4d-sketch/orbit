# Orbit 로컬 소스 정렬·경로·탐색·오류 안내 — 2026-10-26

범위: 정기 검토 R06~R09. 사용자는 수정·검증·설치 교체·실제 화면 확인·GitHub 커밋/푸시·릴리스 파일 갱신을 승인함.

## 변경

- R06: Windows 최종 LocalSnapshot에서 파일 modified·AI 작업 updated 내림차순으로 통합 정렬함. 소스별 30파일·24작업 상한과 불투명 ID 재사용은 유지함. 오늘 화면의 서비스별 최신 항목 선택은 기존 공용 UI를 사용함.
- R07: Windows PathPolicy가 이미 구분자로 끝나는 드라이브 루트에 구분자를 더하지 않도록 경계 접두사를 만듦. 루트 자신은 파일 대상으로 허용하지 않으며 기존 상위 경로·형제 접두사·reparse 검사는 유지함.
- R08: Windows 파일 탐색에서 숨김·점 항목과 node_modules/build/dist/vendor를 제외함. 폴더별 지연 열거 실패를 해당 분기로 제한하고 이미 수집한 정상 파일을 보존함. 하위 분기 실패는 연결됨+부분 검색, 루트 열거 실패는 오류+수집 결과로 표시함. 개수·깊이·시간 상한과 링크 검사를 유지함.
- R09: 파일·AI 탭과 오늘 미리보기에서 초기 읽는 중·연결 필요·정상 빈 결과·읽기 실패·부분 검색을 구분함. 현재 필터의 소스만 안내하며 읽을 수 있는 카드도 함께 유지함. 다시 읽기·연결 설정을 제공하고 원문 예외·개인 경로를 새 안내에 사용하지 않음. 부분 검색 상태의 검색 결과 없음은 읽은 파일 범위로 한정해 설명함.
- 기존 Moss/Pearl/Midnight 테마·인증·D-day·Tasks 쓰기 처리는 유지함. 런타임 의존성·CI·플랫폼 설정은 추가하지 않음.

## 배포 후속

버전 1.0.3(빌드 4)으로 macOS 빌드·서명·DMG 검증을 수행하고, 해당 DMG의 앱을 설치해 실제 화면에서 안내·필터·설정 복구를 확인함. 배포·설치의 실제 결과는 수행 후 아래에 추가함. 현재 이 문장만으로 완료 판정하지 않음.
