## 범위와 완료 기준

기준 커밋은 `482795e`, 대상은 Windows 네이티브 호스트·설정 저장·로컬 제공자다. 사용자 요청에 따라 검토, 수정, 커밋·푸시, 새 Windows 시험판 게시 및 기존 로컬 설치 교체를 수행한다. 성공 기준은 관련 회귀 시험, Windows 전체 gate, 패키지 소스 식별, 설치 파일 해시·실행, 게시 자산 재다운로드 확인이다.

프로젝트의 위임 금지 지침에 따라 직접 검토했다. 자체 검토이며 독립 교차검토로 주장하지 않는다. 공용 Resources와 macOS Sources는 수정하지 않는다. Google 실제 쓰기·인증 변경·시작프로그램·AI 메시지 전송은 범위 밖이다. 실제 Google 계정과 다중 모니터 등 기존 미검증 범위는 시험판의 제한으로 유지한다.

## 후속 개선·검증 순서

1. 사용자 지정 시험 항목이 준비되면 Google 실제 OAuth·Calendar·Tasks 완료/되돌리기 검증. 이번 합성 HTTP 시험과 구분한다.
2. 실제 ACL·junction·클라우드 reparse 장치, 다중 모니터·배율 전환을 별도 장치 시나리오로 검증한다.
3. 배포 범위를 넓히기 전에 코드 서명과 설치 프로그램 도입 여부를 결정한다. 이번에는 기존 방식의 서명 없는 self-contained ZIP 시험판으로 배포한다.

패키지·설치·게시의 최종 증거는 `Windows/VERIFICATION.md`의 이번 날짜 기록에 추가한다.
