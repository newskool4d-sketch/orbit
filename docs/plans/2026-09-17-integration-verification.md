# Orbit 글자 크기·D-day 통합 검증

검증일: 2026-09-17. SDK 설치·전체 Windows 빌드·새 WebView2 기본 검증·프로세스 재시작 복원: **PASS**. 전체 플랫폼·OS 배율 검증: **PARTIAL**.

후속 승인에 따라 Microsoft 공식 SDK 10.0.400 win-x64 ZIP을 SHA-512 검증 후 `%LOCALAPPDATA%/OrbitDevelopment/dotnet-10.0.400`에 설치했다. 시스템 PATH와 기존 설치본은 변경하지 않았다. 전체 빌드 경고 0·오류 0, 새 실행 파일 자체 시험 64/64, 공용 시험 35/35, 저장소·정책 단독 시험 36/36이 통과했다. 단독 저장소 시험과 네이티브 자체 시험에는 중복되는 항목이 있으므로 합산 시험 수로 표현하지 않는다.

실제 WebView2에서 합성 항목의 등록·편집·중요·보관·복원·삭제와 3개 테마 × 3개 크기 관리 화면을 확인했다. 9개 조합의 가로 넘침 검사가 통과했고 캡처 9장을 생성했다. 격리한 임시 저장소에서 앱 프로세스를 두 번 실행해 D-day와 `xlarge` 설정 복원을 확인했고, 검증 실행이 저장 파일을 변경하지 않았음을 SHA-256으로 확인했다. `Windows/artifacts/qa/sdk-build-verification.json`에 SDK ZIP SHA-512와 새 실행 파일 SHA-256 및 결과를 보관했다.

## 발견 및 수정

1. 등록 응답 대기 중 재제출이 중복 항목을 만들 수 있어, 저장·목록 변경을 잠그고 완료 후 해제했다.
2. 관리창 안에서 편집을 누르면 닫기 후 숨겨진 내부 버튼으로 포커스가 돌아가던 문제를 수정했다. 배경 요소를 inert 처리하고 Tab 순환을 추가했다.
3. 일반 새로고침마다 관리 목록을 다시 생성하던 동작을 바꿔 변경 없는 목록의 포커스와 삭제 확인을 보존했다.
4. 생성 시각이 같으면 무작위 ID 순으로 바뀌던 정렬을 수정해 저장된 생성 순서를 유지했다.
5. 브라우저에서 0000년·제어 문자를 허용하던 입력 검사를 네이티브와 맞췄다. Swift 제목 길이도 UTF-16 120자로 맞췄다.
6. Windows에서 `{}` 또는 필수 필드 누락 파일을 빈 정상 저장소로 읽던 문제를 필수 JSON 필드 검사로 막았다.
7. Windows 글자 크기 저장 실패 시 메모리 설정을 이전 값으로 되돌리도록 수정했다. 전체 WPF 빌드는 통과했으나 실제 설정 파일 쓰기 실패를 주입하는 시험은 남음.
8. 자정 단발 갱신과 표시 상태·포커스 복귀 시 재계산을 추가했다. 숨김 상태에서는 추가 타이머를 유지하지 않는다.
9. 오래된 실행 파일로 네이티브 시험이 성공하는 혼동을 막기 위해 소스보다 오래된 바이너리는 시험 시작 전에 차단한다.
10. Windows Resume 이벤트에서 D-day 시계와 로컬 데이터를 다시 읽도록 연결하고, 네이티브 UI 시험에 키보드·Resume 회귀 검사를 추가했다.
11. 사용자 설정과 분리한 QA 저장소에서 앱을 두 번 실행해 D-day·글자 크기 복원을 검증하고 시험 후 임시 데이터를 제거한다.
12. 150%·아주 크게와 200% 배율 상당 시험에서 하단 연결 상태 영역의 가로 넘침을 발견해 좁은 화면에서 줄바꿈하도록 수정했다. 200% 고배율 탭도 단어 단위 한 줄을 유지하도록 간격과 보조 글자 크기를 조정했다.
13. 최신 CSS가 배포 폴더에 복사됐어도 EXE 시각만 비교해 실패하던 검증기를 원본·배포 리소스 SHA-256 비교로 수정했다.

## 남은 검증 순서

1. 100·200%를 지원하는 다른 장치와 다중 모니터에서 실제 배율을 추가 확인. 현재 장치의 125·150·175%와 100·200% 상당 자동 렌더링은 통과함.
2. macOS에서 `bash scripts/build.sh`, `build/Orbit.app/Contents/MacOS/Orbit --self-test`, 실제 화면 확인.

초기 검증 단계에서는 설치본 교체·외부 데이터 변경·커밋·푸시를 하지 않았다.

## 설치·패키지 후속 결과

사용자 승인에 따라 `%LOCALAPPDATA%/Programs/Orbit` 설치본을 새 후보로 교체했다. 시작 메뉴 바로가기와 기존 사용자 설정 파일 해시는 유지됐고, 설치 경로에서 자체 시험과 WebView2 UI smoke를 통과했다. 이전 설치본은 `Orbit.rollback-20260917-103536`에 보존했다.

글래스 표면과 Windows 글꼴 개선을 반영한 패키지는 `Orbit.Windows-<빌드시각>.zip` 형식으로 생성한다. checkout 밖의 새 폴더에 압축 해제해 자체 시험·UI smoke를 재실행했고, 외부 `.sha256` 파일과 설치본 DLL·스타일 리소스 동등성을 확인했다. 자세한 증거는 `2026-09-17-windows-release-evidence.md`에 기록했다.

실제 배율 전환과 물리 절전·복귀를 완료했다. 현재 장치의 지원 범위는 125·150·175%이며, 100·200%는 실제 적용되지 않아 자동 배율 상당 검사 결과로 구분해 기록했다.
