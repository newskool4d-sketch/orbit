ORBIT · GOOGLE CONNECTION

한 번 연결하면,
매일의 흐름이 한눈에.

Orbit은 개인용 로컬 앱입니다. Google의 데스크톱 OAuth 클라이언트가 필요합니다. 기존 Codex·Claude 커넥터 로그인은 별도 앱인 Orbit에 이전되지 않습니다.

  1. Google Cloud Console에서 사용할 프로젝트를 선택합니다.
  2. API 라이브러리에서 Google Calendar API와 Google Tasks API를 활성화합니다.
  3. Google Auth Platform에서 앱 이름을 Orbit으로 설정합니다. 테스트 상태라면 Audience의 테스트 사용자에 본인 Google 계정을 추가합니다. 조직 계정은 관리자 정책에 따라 연결 승인이 필요할 수 있습니다.
  4. Clients에서 OAuth 클라이언트를 만듭니다. 유형은 반드시 Desktop app / 데스크톱 앱을 선택하고 JSON을 다운로드합니다.
  5. Orbit의 설정 → OAuth JSON 가져오기에서 이 파일을 선택합니다.
  6. Google 연결을 누르고 브라우저에서 본인 계정으로 로그인합니다. 요청 권한은 Calendar 읽기와 Tasks 읽기·쓰기입니다. 동의 화면은 직접 확인하고 진행하세요.

연결 후

선택·표시 중인 캘린더의 앞으로 7일 일정, Google Tasks 목록을 가져옵니다. 체크박스를 누르면 Google Tasks에도 완료 상태가 반영됩니다. 토큰은 macOS 키체인에 저장되며, 파일이나 노트 내용은 Google에 전송하지 않습니다.

연결이 끊겼다면

앱의 연결 상태에서 오류를 확인하세요. 테스트 상태인 외부 OAuth 앱은 갱신 토큰이 만료될 수 있어 재연결이 필요합니다. 403 오류는 API 활성화, 동의 범위, 조직 정책을 확인하세요. 연결 해제는 이 맥에서 Orbit의 로그인 정보를 제거합니다. Google 계정 자체의 앱 접근 철회는 Google 연결 관리에서 할 수 있습니다.
